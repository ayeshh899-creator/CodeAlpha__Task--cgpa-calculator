# CodeAlpha — CGPA Calculator

## Project Overview
A C++ program that calculates a student's GPA and CGPA based on course credits and letter grades (A, B, C, D, F).

## Features
- Calculates GPA for any number of courses
- Supports letter grades A, B, C, D, F
- Shows total credits and total grade points
- Displays GPA rounded to 2 decimal places (using setprecision)
